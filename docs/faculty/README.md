# Docs

Faculty guidance for this Golden Template.


| Guide | For | Time |
|---|---|---|
| **[Adapting the C# code template](getting-started.md)** | Replacing projects and tests while keeping the solution, references, NuGet packages, and CI aligned. | ~30 min |
| **[Classroom 50's Web UI](classroom-50-setup-web.md)** | Using the Classroom 50 web UI to set up a classroom and auto-graded assignment. | ~45 min first time |
| **[Classroom 50's CLI](classroom-50-setup.md)** | The same path using `gh teacher` and `gh student` on a command line, instead of the web UI. | ~45 min first time |
| **[C50 autograder with the Web UI](writing-tests-web.md)** | Configuring your tests to run on the C50 autograder, using the web UI. | ~20 min |
| **[C50 autograder with the CLI](writing-tests.md)** | The same path using `gh teacher`. | ~20 min |
| **[Troubleshooting](troubleshooting.md)** | Something is broken. Symptom → diagnosis → fix. | as needed |
| **[Governance](governance.md)** | Adapting the template for your course. The recommended baseline is advisory; nothing here is mandatory. | ~10 min |
| **[Performance sanity check](../../perf/README.md)** | Load testing a service-building assignment. Opt-in. | ~10 min |
