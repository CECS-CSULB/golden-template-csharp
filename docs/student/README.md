# Student Documentation

These guides explain the practical steps for working with this C# assignment
from your computer and GitHub. Start with
[STUDENT_README.md](../../STUDENT_README.md), the primary source of the
assignment requirements, then use the guide that matches what you are trying
to do.

## Guides

| Guide | Consult it when you need to... |
|---|---|
| [Initial Git and GitHub Setup](github.md) | Install Git, configure your identity, sign in to GitHub, and connect your local repository. Git Credential Manager is the preferred sign-in method. |
| [Everyday Git Workflow](git-workflow.md) | Review changes, save focused commits, pull instructor-provided updates, push checkpoints, and recover from common local mistakes. |
| [Student Build Guide](setup.md) | Install the .NET 10 SDK, restore dependencies, build the solution, run the program, and run the xUnit test suite. |
| [Development Cycle](development-cycle.md) | Follow the normal workflow from understanding requirements through development, testing, committing, final review, pushing, and monitoring CI. |
| [Writing a Professional README.md](writing-a-readme.md) | Write clear, accurate documentation for a public portfolio repository. |
| [Publish Your Completed Assignment](publishing.md) | Publish approved work to a public repository on your personal GitHub profile after the semester. It covers checking for private course material, creating a portfolio repository, and pushing only the approved history. |

## Recommended order

1. Read [STUDENT_README.md](../../STUDENT_README.md) to understand the
   assignment requirements and deliverables.
2. Read [Using Git and GitHub from the Command Line](github.md) if Git is not
   installed or you have not connected Git to your GitHub account.
3. Use [Everyday Git Workflow](git-workflow.md) for routine Git work after the
   initial GitHub setup.
4. Follow the [Student Build Guide](setup.md) to configure, build, and test the
   project locally.
5. Follow the [Development Cycle](development-cycle.md) while working through
   the assignment.
6. After your instructor approves publication, read [Writing a Professional
   README.md](writing-a-readme.md) and prepare the project documentation.
7. After the semester—and only after your instructor gives permission—read
   [Publish Your Completed Assignment](publishing.md) before making the project
   public.

You do not need the publishing guide during normal assignment work. Public
publication is optional and should wait until you have confirmed that the
repository contains no solutions, hidden tests, private course files, secrets,
or other students' information.
